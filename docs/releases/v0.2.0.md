Aero 0.2.0 brings Chrome extensions into Aero and adds more native ways to handle websites and files.

## Extensions

- Install extensions from the Chrome Web Store or an unpacked folder, with a review of their site access and permissions before they run. Extensions and their data stay in the profile where you install them.
- Extension buttons, popups, menus and keyboard shortcuts work in Aero. Extensions can also open tabs and popup windows, replace the New Tab page, and connect to permitted desktop apps.
- More extension features now work, including notifications, downloads, history and sign-in windows. Aero checks for store updates and asks again when an update requests more access.
- Settings shows an extension's access, shortcuts, connection errors and features Aero cannot support.

## Browsing and files

- Website popups that request a size open in their own window; other popups open in tabs. Both keep their connection to the page that opened them.
- Website alerts, confirmations and prompts appear in Aero. File inputs use the Mac's open panel, and you can stop a page from showing more dialogs until it loads another document.
- Open local pages, web archives, images, PDFs and text files from Aero or the Finder. Save a page as a web archive or export it as a PDF.
- Download progress appears in the Finder and Dock. Developer mode adds Web Inspector to pages and extensions.

## Current limits

- Some Chrome extension features remain unavailable; Aero lists them during installation and in Settings.
- Aero does not fill passwords in separate website popup windows yet.
