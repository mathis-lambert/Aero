Aero 0.4.2 keeps opened tabs stable while switching, adds a visual Ctrl-Tab chooser, and requests native macOS passkey access.

## Tab switching

- Switch between opened tabs and favorites without rebuilding their page containers or resetting their viewport.
- Hold Control and press Tab to browse recent tabs in the current space, including opened favorites, with cached thumbnails, titles and site icons.
- Use Shift to move backwards or the arrow keys to choose a tab. Release Control or press Return to switch; press Escape to cancel.
- Pages stay in place while you choose. Thumbnails use a small memory cache and fall back to a site icon when unavailable.

## System passkeys

- Aero requests macOS browser passkey access when the browser is ready and in the foreground, after onboarding.
- Password settings show the permission state and explain how to restore access after a refusal in macOS Privacy & Security.
- Websites continue to use the native system sign-in window. A stalled macOS authentication service may still prevent that window from opening; browser permission does not resolve every system-service failure.
