Aero 0.4.1 adds an optional import from Dia, a quick way to close a space’s open tabs, and a fix for a New Tab crash.

## Import from Dia

- Read your spaces and favorite tiles directly from the running Dia app after granting macOS Automation permission.
- Preview the import before adding it to Aero. File import remains available for history and passwords.
- The direct import reads current page titles and addresses. It cannot import folders, tabs inside folders, open tabs, space colors or shared profile assignments. Each imported space gets a separate Aero profile.

## Tabs

- Hover over the separator between favorites and open tabs to reveal a small Close All button. It closes the current space’s ordinary tabs while keeping favorites and other spaces intact.
- Closed tabs remain available through Reopen Closed Tab.

## Fixes

- Fixed a crash when opening New Tab after closing tabs.
